# Siteyi Yık! 💥

## Çalıştırma
1. https://nodejs.org adresinden Node.js (LTS) kur
2. Bu klasörde terminal aç:
   npm install
   npm start
3. Tarayıcıda aç: http://localhost:3000

## Dosyalar
- server.js       → DERS 1: siteyi çekip içine oyunu koyan sunucu (proxy)
- public/game.js  → DERS 2: oyunun kendisi (harita, fizik, silahlar, yıkım)
- public/index.html → URL yapıştırılan giriş sayfası
- public/demo.html  → internetsiz test sayfası
